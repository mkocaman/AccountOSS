## 🎯 **Proje Özeti**

AccountOS, modern ERP ve muhasebe sistemi olarak geliştirilen kapsamlı bir web uygulamasıdır. .NET 8 Web API backend ve React + TypeScript frontend teknolojileri kullanılarak geliştirilmiştir.

---

## 🏗️ **Teknik Altyapı**

### **Backend (.NET 8)**
- **Framework:** .NET 8 Web API
- **Veritabanı:** PostgreSQL
- **ORM:** Entity Framework Core
- **Kimlik Doğrulama:** JWT Authentication
- **Mimari:** Clean Architecture (Domain, Application, Infrastructure, API)
- **Pattern:** CQRS (Command Query Responsibility Segregation)

### **Frontend (React)**
- **Framework:** React 18 + TypeScript
- **Build Tool:** Vite
- **UI Library:** Ant Design + Ant Design Pro 6
- **State Management:** Zustand
- **Data Fetching:** React Query
- **Routing:** React Router DOM
- **Internationalization:** i18next
